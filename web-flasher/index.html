HA Knob web flasher

Installs HA Knob __VERSION__ (firmware and setup web UI) on a LilyGo T-Encoder Pro over USB, straight from the browser.

This browser cannot talk to USB serial devices. Use Google Chrome or Microsoft Edge on a desktop computer (Windows, macOS, Linux or ChromeOS).

Installing only works on an HTTPS page (or on localhost).

What you need

  • Google Chrome or Microsoft Edge on a desktop computer. Firefox, Safari and phones have no Web Serial support.
  • This page over HTTPS (it is).
  • A USB-C cable that carries data, plugged straight into the T-Encoder Pro.

Install

  1. Plug in the T-Encoder Pro and click Install HA Knob __VERSION__.
  2. Pick the device in the port list (usually "USB JTAG/serial debug unit") and click Connect.
  3. Click Install HA Knob, tick Erase device or leave it unticked (see below), click Next, confirm, and wait until the install has finished. The device restarts by itself.

Erase or keep the settings

Without "Erase device" (update)
Only the firmware, the setup web UI and the boot data are written. The settings area at the end of the flash is not touched, so the Wi-Fi network, the Home Assistant address and token, the controls, the device settings and the setup access point password are all kept.
With "Erase device"
The whole flash is erased first. This removes every setting: Wi-Fi network and password, Home Assistant address and token, controls, device settings, the web UI password and the setup access point password. On the next start the device generates a new setup access point password and shows it on the screen. (The factory-reset gesture on the device keeps the access point password; erasing here does not.)

Tick "Erase device" for the first install, or when the device ran other firmware before.

After the install

This installer does not set up Wi-Fi. On a new or erased device, HA Knob opens its setup access point: the screen shows its name (HA-Knob-XXXX) and password. Join it with a phone or laptop; the setup page opens by itself, or go to http://192.168.4.1/. Then follow First-time setup in the README.

If the device is not found or the install fails

Put the board in download mode by hand: hold the knob pressed (it is the BOOT button, IO0) while you plug in the USB cable or press reset, then release it and click Install again. When the install has finished, unplug the cable and plug it in again without holding the knob.

Do not hold the knob while the device starts normally: that always enters download mode instead of starting HA Knob.

Other ways to flash

The release v__VERSION__ has the separate images, flash_args.txt, checksums and a merged image for esptool:

esptool.py --chip esp32s3 write_flash 0x0 ha-knob-__VERSION__-merged.bin

The merged image ends before the settings area, so it keeps the settings like an update here. Building from source with PlatformIO is described in the README.
