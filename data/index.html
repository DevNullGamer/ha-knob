    Certificate (https)

    Leave the field empty if Home Assistant uses a certificate from a public certificate authority (e.g. Let's Encrypt). For a self-signed certificate or your own CA, paste the CA certificate: only the -----BEGIN CERTIFICATE----- ... -----END CERTIFICATE----- block(s), up to 3, nothing else (no subject= lines, never a private key).

    With an IP address in the address above, the certificate is only accepted if its name (CN) is exactly that IP address and it has no other names (SAN). Otherwise use the host name the certificate was issued for. The device supports TLS 1.2 and does not check certificate expiry dates.

    Certificate verification is off: anyone who can intercept the connection can pretend to be Home Assistant and capture the token. Use this only on a network you trust.

    Create the token in Home Assistant under your user profile, Security, "Long-lived access tokens". Use a dedicated non-admin user for the knob. A new address (another host or port) always needs the token again, and so does a weaker certificate check (turning verification off or a different CA certificate).
